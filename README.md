# Gareeb Tech Team - WhatsApp Group Manager

Professional WhatsApp group moderation system blueprint.

Features:
- Lifetime warning tracking
- 1st Warning / Final Warning / Automatic Removal flow
- Spam detection
- Allowed links: YouTube, Zoom, Google Meet, Microsoft Teams
- Block WhatsApp links and unknown domains
- Country restriction: +94, +974, +971 only
- Works only when bot account has group admin permission
- Existing authentication system integration

Note:
Configure your WhatsApp automation provider and existing authentication API before production deployment.
